# Pet Store Application

Welcome to the **Pet Store Application**! This is an interactive project built using **JavaFX** where users can browse, choose, and purchase pets from a variety of options. The app includes a **login system** for users and an **admin panel** to manage pets and users.

## Features

- **Browse Pets**: Choose from a variety of pets available for adoption.
- **Purchase Pets**: Select your desired pet and proceed to purchase.
- **User Login**: Log in securely using your **email** and **password**.
- **Admin Panel**: Admins can manage pets, users, and purchases from a dedicated panel.

## Technologies Used

- **JavaFX**: A framework for building the graphical user interface (GUI) of the application.
- **Database**: Stores user and pet information into a txt file.
- **Authentication**: Login system implemented using **email** and **password**.
